# Package Contents

## Required Installation Files

| Item | Destination | Purpose |
|---|---|---|
| `WaysAround.rmg.json` | `HeroesOldenEra_Data/StreamingAssets/map_templates/` | Main template definition. |
| `WaysAround.png` | `HeroesOldenEra_Data/StreamingAssets/map_templates/` | Preview image shown by the game. |
| `WaysAroundAssets.zip` | `HeroesOldenEra_Data/StreamingAssets/` | Required asset archive. |

## `DB/` Source Files

These source files are already packaged inside `WaysAroundAssets.zip`. They are included in the repository for inspection and modification, but are not needed for installation.

| Source path | Purpose |
|---|---|
| `DB/buildings_constructions/ways_around_buildings_presets.json` | Building presets for Spawn, Side, and Center towns. |
| `DB/buildings_bans/ways_around_buildings_bans.json` | Central-town construction ban list. |
| `DB/map/objects/ways_around_flattering_mirrors.json` | Template-specific World Mirror objects. |
| `DB/objects_logic/event_banks/vision_banks/ways_around_flattering_mirrors.json` | World Mirror reveal behavior. |
